# Changelog

All notable changes to this repository are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-25

### Added

- Examples for curl, Python, Node.js, Go, PHP, Bash and PowerShell.
- Webhook receivers with signature verification for Flask and Express.
- Recipes for Home Assistant, Uptime Kuma, n8n, cron/systemd and GitHub Actions.
- OpenAPI 3.1 description of the curl-sms API (`openapi.yaml`).
- CI that lints every example and runs a live smoke test with a test key.
